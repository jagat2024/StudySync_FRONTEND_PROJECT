# 🌟 StudySync

A modern and responsive frontend landing page designed for an online learning platform.  
This project focuses on creating a clean UI/UX experience with responsive layouts, smooth animations, interactive components, and dark mode support.

Built using pure **HTML, CSS, and JavaScript** without any frameworks.

StudySync includes a fully functional dark mode built using CSS variables and JavaScript theme toggling.

```js
document.body.classList.toggle("dark");
```
